# 品質自檢清單

每個階段完成後，挑對應段落逐項檢查，並在成品末尾附上結果：

```markdown
## 自檢結果
| 項目 | 結果 | 備註 |
|------|------|------|
| Logline 30 字內 | ✅ | 26 字 |
| 付費卡點已標記 | ⚠️ 需修改 | 第 10 集情緒值 +2，卡點不夠懸 |
```

## 企劃書

- [ ] Logline 30 字內，包含主角、困境、目標、阻礙
- [ ] 核心爽點類型明確（1–2 種）
- [ ] 三幕結構的集數區間合計等於總集數
- [ ] 第一付費卡點已規劃
- [ ] 列出世界觀禁忌，且之後的成品沒有違反
- [ ] 「採用的假設」已列出

## 角色表

- [ ] 主要角色 3–6 人
- [ ] 每個角色外型描述具體到可生成定裝圖
- [ ] 反派有明確動機
- [ ] 至少一個角色有隱藏身分，且已規劃揭露集數
- [ ] 關係矩陣中每對主要角色都有張力或連結
- [ ] 角色名字之間容易區分（不同字首、不同字數；同姓家人可例外，但劇中稱呼要不同）
- [ ] 每個角色有全劇唯一、一眼可分的代號

## 分集大綱

- [ ] 每集都有開場鉤子、爽點或反轉、結尾鉤子
- [ ] 沒有連續 3 集以上情緒值同號
- [ ] 每 10 集至少一個 +4 以上的大爽點（迷你劇：全劇至少一個）
- [ ] 付費卡點集的結尾情緒值 ≤ -3 或懸念最高
- [ ] 同一反轉橋段沒有在 5 集內重複使用
- [ ] 前後集因果連貫，伏筆追蹤表中每個伏筆都有回收集數（或明確留作續集）
- [ ] 主角靠自己的選擇脫困，不靠巧合

## 劇本

- [ ] 開場 3 秒內出現衝突、懸念或強情緒
- [ ] 每句對白不超過 20 字
- [ ] 動作描述只寫看得見、聽得見的東西
- [ ] 已標記 `【爽點】`、`【反轉】`、`【鉤子】`
- [ ] 主爽點約在全集 65%–90% 處（90 秒集約 60–80 秒）；提前時註明原因
- [ ] 付費卡點集：前半兌現一個爽點，集尾停在全劇最大懸念
- [ ] 估算時長在目標 ±15% 內（公式見 `pacing-rules.md`「時長估算」）
- [ ] 角色說話風格與角色表一致
- [ ] 沒有違反世界觀禁忌或人物設定

## 分鏡

- [ ] 每鏡都有鏡號、時長、景別、角度、運鏡、畫面內容
- [ ] 總時長與劇本估算一致
- [ ] MCU 與 CU（含 ECU）佔多數；LS 以上鏡頭不超過 20%（OTS、POV 依實際取景歸類）
- [ ] 單鏡時長不超過 6 秒（空鏡、慢動作除外）
- [ ] 每個情緒轉折至少一個特寫
- [ ] 爽點鏡頭有慢動作、推鏡或重擊音效標註
- [ ] 集尾為切黑或停格在關鍵反應

## AI 提示詞

- [ ] 每個主要角色都有錨點與定裝提示詞
- [ ] 每鏡的角色描述與錨點一致，沒有自行改寫
- [ ] 反覆出現的地點有場景錨點
- [ ] 送出前所有 `[代號]` 都已換成錨點全文
- [ ] 每鏡只有一個主要動作
- [ ] 每鏡都寫了 `vertical 9:16`
- [ ] 畫面中需要的文字已改為後製處理
- [ ] 沒有要求模仿真實人物的長相或聲音

## 內容邊界

- [ ] 沒有露骨性內容
- [ ] 暴力與霸凌服務於敘事，沒有細節渲染
- [ ] 沒有以族群、外貌、身心障礙作為羞辱笑點
- [ ] 改編作品已提醒授權問題
